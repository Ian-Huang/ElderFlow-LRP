## 關鍵決策：Mock-First 契約

| 契約定義位置 | 用途 |
|-------------|------|
| `packages/shared` | TypeScript 介面 (Request/Response DTO) |
| `apps/web/src/mocks/handlers/` | MSW handlers — **前端開發期的單一真實來源** |
| `apps/api/src/openapi.ts` | 後端實作時對齊的 OpenAPI 3.0 spec |

**前後端同步機制：**
1. 前端先寫 MSW handlers，定義 API 回應結構
2. 後端實作時**嚴格對齊** MSW 回應結構 (欄位名、型別、巢狀結構)
3. Ticket 20 契約測試自動比對：`MSW handler 回應` vs `後端實際回應` → 不一致即失敗
