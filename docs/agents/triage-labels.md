# 分流標籤

技能以五個標準分流角色溝通。此檔案將這些角色對應到本倉庫問題追蹤器實際使用的標籤字串。

| mattpocock/skills 的標籤 | 我們追蹤器的標籤 | 含義 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 維護者需評估此問題 |
| `needs-info`               | `needs-info`         | 等待回報者補充資訊 |
| `ready-for-agent`          | `ready-for-agent`    | 規範完整，可交給 AFK agent |
| `ready-for-human`          | `ready-for-human`    | 需人工實作 |
| `wontfix`                  | `wontfix`            | 不處理 |

當技能提到某角色（例如「套用 AFK-ready 分流標籤」），請使用此表對應的標籤字串。

請修改右欄以符合您實際使用的詞彙。
